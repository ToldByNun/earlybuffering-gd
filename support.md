# Support

For v1.6.0 Cloud Config issues, include whether browsing, installing, sharing or ratings failed and the popup error. The entry is under **Settings → Learn → Config → Cloud Configs** (desktop menu) or the classic Assist actions row. Config installation may change assist settings. See [Cloud Configs](docs/cloud_configs.md). For Adaptive Plan / Live Delay misses, attach a DevTrace session + `earlybuffer-dev-report.txt` when possible. On Android `Unable to read entry (code -3)`, re-download a **v1.6.0+** deflate package (not a zstd v1.5.1 zip).

- **Discord:** [https://discord.gg/QJuTDkmPcf](https://discord.gg/QJuTDkmPcf) — questions, feedback, and discussion.
- **Bugs / crashes:** open a [GitHub issue](https://github.com/ToldByNun/earlybuffering-gd/issues) with GD version (**2.2081**), Geode version, platform, and steps. Attach Geode crashlogs when possible. For death/reset hitch reports, enable **Lag Probe** and attach `earlybuffer-lagprobe.log` from the mod save folder.
- **Settings questions:** see the in-mod setting descriptions and [`docs/assist_reference.md`](https://github.com/ToldByNun/earlybuffering-gd/blob/main/docs/assist_reference.md).
- **Fair play:** use **Safe Mode**; do not expect assisted runs to be valid for leaderboards or community standards.
- **Version:** **v1.6.0** is the current EarlyBuffer package line for **GD 2.2081** (desktop menu, Live hitch / Wave IW / orbs-under-IW, Adaptive Prediction Planner, Cloud Configs). Issues on other GD builds are out of scope for this line. See [`changelog.md`](changelog.md).

Maintainer: **Audesign**. Prefer reproducible reports (steps, logs, settings) over vague “it lags” notes.
