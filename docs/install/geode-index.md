# Geode Index — banned

EarlyBuffer is **not available** on the Geode Index (banned / removed). Searching for it under Geode → Download will not give a working official listing.

## What to do instead

1. Install from [GitHub Releases](/install/github-releases)
2. Or [build from source](/install/from-source)
3. Still install dependency **geode.node-ids** from the Index if Geode asks for it — that dependency is separate

## Why this page exists

So people do not think the docs are outdated when Index search fails. The supported public install path is **GitHub**.
