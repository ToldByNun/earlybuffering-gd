# Install overview

::: warning Not on the Geode Index
EarlyBuffer is **banned / unavailable on the Geode Index**. You cannot install it from Geode → Download. Use **GitHub Releases** (or a trusted copy of the `.geode`), or build from source.
:::

Pick **one** path:

| Method | Best for | Link |
|---|---|---|
| **GitHub Releases** | Everyone | [GitHub Releases](/install/github-releases) |
| Phone | Android / iOS | [Mobile](/install/mobile) |
| Build yourself | Devs / testers | [From source](/install/from-source) |
| Geode Index | — | [Why it is gone](/install/geode-index) |

## Checklist before you start

- [ ] GD **2.2081**
- [ ] Geode **5.11.1+** (loader only — Index is not used for this mod)
- [ ] You know your platform (Windows / macOS / Android / iOS)
- [ ] Dependency **geode.node-ids** ≥ v1.23.3 (install that from the Index if needed)
- [ ] For phone: the `.geode` must include the phone binary (not Windows-only)

::: warning Wrong game version
EarlyBuffer **1.5.x** is built for **2.2081 only**. Newer Geometry Dash builds need a future port.
:::

## After install

1. Drop the `.geode` into your Geode mods folder (or use Geode’s “install from file” if available).
2. Restart Geometry Dash (or reload mods).
3. Confirm **EarlyBuffer** shows in the mods list.
4. Open settings → follow [Quick start](/start).
