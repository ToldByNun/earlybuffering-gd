# Features

Short list of what EarlyBuffer can do. Each item has a deeper page.

| Feature | One-line meaning |
|---|---|
| [Assist modes](/features/modes) | Live / Hybrid / Replay / BruteForce — how timing is chosen |
| [Adaptive Plan](/features/adaptive) | Smarter Live planner (screen → verify → decide) |
| [Cloud Configs](/features/cloud-configs) | Download / share settings packs |
| [Safe Mode](/features/safe-mode) | Do not treat assisted runs as normal clears |
| [Bake & Trigger World](/features/bake) | Precomputed windows + mover/toggle cache for the sim |
| Scope gates | Practice / start-pos / percent / off-ranges |
| Learning / Self-bake | Optional; off by default |
| Overlay / pause EB | Status line + settings button |
| Save feedback | Sound / color / counter when a delay actually fired |

## What it is **not**

- Not an autoplayer
- Not a bot that plays the whole level for you
- Not late-forgiveness (it will not rewind a click that was already too late)

You still decide **when** to jump. EarlyBuffer only nudges **which tick** that jump lands on inside your window.
