# Cloud Configs

Browse community settings packs, install them, rate them, and share your own.

## Open it

**Settings → Assist → Assist Actions → Cloud Configs**  
(directly under **Import Config**)

## What install does

- Applies the pack’s assist settings
- Keeps your **keybinds** and **developer** settings
- Can change how strong / floaty assist feels — read the pack notes

## Offline

Cached packs and bundled defaults still work without network. Online browse needs HTTPS to the configured endpoints.

## Share

Share submits a pack for review. Do not share secrets; settings packs are for assist preferences.

Tech endpoints / behavior: [Cloud configs (tech)](/cloud_configs).
