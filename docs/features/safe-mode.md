# Safe Mode

Setting: **Main → Safe Mode** (default **On**).

## What it means

While EarlyBuffer is enabled — or after assist actually delayed a click this attempt — the mod treats progress / bests / percentage as **not a normal vanilla clear**.

## Keep it on when

- You play rated / online
- You care about “was this run assisted?”
- You are unsure

## Turn off only if

You understand progress can save like vanilla even if assist fired, and you accept that.

::: danger Rated clears
If you post clears, keep Safe Mode **on** unless the rules of that space say otherwise. EarlyBuffer is tagged as a cheat-style assist for a reason.
:::
