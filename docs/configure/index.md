# Settings map

Open settings from **Geode → EarlyBuffer** or pause → **EB**.

| Tab | What lives there |
|---|---|
| [Main](/configure/main) | Enabled, Safe Mode, Assist Mode, Window unit + sizes, smart / adaptive prediction |
| [Assist](/configure/assist) | Where it runs (ex-Scope), algorithm (pick, engine, orbs, budgets) |
| Learn | Learning toggles + config import/export / Cloud Configs |
| Bake | Import / bake actions, trigger world |
| [Modes](/configure/modes) | Icon picker + per game-mode overwrite windows |
| Visual | Trajectory / bake path + save feedback |
| UI | Accent Color, overlay / pause chrome, light diagnostics |
| [Keys](/configure/keys) | Hotkeys |
| Dev | Session / eval / overlay tools (for debugging) |

## Golden rule

Change **one** setting, play 2–3 attempts, then decide.
