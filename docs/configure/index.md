# Settings map

Open settings from **Geode → EarlyBuffer** or pause → **EB**.

| Tab | What lives there |
|---|---|
| [Main](/configure/main) | Enabled, Safe Mode, Assist Mode, Window unit + sizes, overlay / pause chrome |
| [Scope](/configure/scope) | Practice / start-pos / percent / off-ranges (platformer always off) |
| [Assist](/configure/assist) | Pick, engine, orbs, budgets, Adaptive, learning, trigger world, cloud actions |
| Bake | Import / bake actions, cycle mode |
| [Modes](/configure/modes) | Per game-mode overwrite windows (cube, ship, ball, …) |
| [Keys](/configure/keys) | Hotkeys |
| Dev | Session / eval / overlay tools (for debugging) |

## Golden rule

Change **one** setting, play 2–3 attempts, then decide.

## Starter profile

Copy of the [Quick start](/start) table: Live, Safe Mode on, Window 4/4 ticks, Adaptive off, Learning off.
