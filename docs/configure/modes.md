# Per game-mode windows

Under **Modes** you can overwrite the default window for:

Cube, Ship, Ball, UFO, Wave, Robot, Spider, Swing

## Pattern

1. Turn **Overwrite** on for that mode  
2. Set that mode’s window  
3. Leave others off → they use Main → Window (Default) / Wave default

## Adaptive Overwrite

Each mode also has **Adaptive Overwrite**.

1. Leave it off → that mode uses **Main → Adaptive Prediction**
2. Turn it on → set Adaptive Plan / Screen Ticks / Verify Quantum / Reserve % for that mode only

Wave Adaptive on does not change Cube while Cube Adaptive Overwrite is off.

## Tips

- Wave: keep small
- Ship / swing: continuous control feels different — do not copy cube numbers blindly
- Ball: landing / input-window behavior can differ from cube; change slowly

If overwrite is off, the Main window values apply.
