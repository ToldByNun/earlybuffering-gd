# Keys & extras

## Hotkeys

Hotkeys live on their feature tabs (there is no separate Keys tab). Defaults include (you can rebind):

- **UI** — Desktop Menu
- **Assist** — Cycle Assist Mode (often Ctrl+Shift+M)
- **Learn** — Auto-Tune, Reset Level Learning
- **Visual** — Trajectory Viz
- **Dev** — Debug Logging

If a hotkey fights another mod, rebind EarlyBuffer’s key — do not leave two mods on the same combo.

## Save Feedback

When a delayed click actually fires, optional:

- Sound
- Color flash
- Counter (`+N` / streaks) — `+N` is physics ticks held before inject, not “saved”

These are feedback only — they do not change the plan.

## Import / Export / Cloud

Desktop menu: **Learn → Config**. Classic popup: Assist Actions.

- Export your settings
- Import a friend’s JSON
- Open [Cloud Configs](/features/cloud-configs)

Keybinds + Dev settings are preserved across cloud installs.

## UI extras (v1.7.x / v1.8.0)

**Accent Color**, overlay / pause chrome, and **Lag Warning** live under the **UI** tab. Ship / Wave corridor assists live under **Flight**; viz toggles stay on **Visual**.
