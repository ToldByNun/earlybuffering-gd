# Keys & extras

## Hotkeys

Defaults include (you can rebind):

- Cycle Assist Mode (often Ctrl+Shift+M)
- Other cycle / debug binds listed in **Keys**

If a hotkey fights another mod, rebind EarlyBuffer’s key — do not leave two mods on the same combo.

## Save Feedback

When a delayed click actually fires, optional:

- Sound
- Color flash
- Counter (`+N` / streaks)

These are feedback only — they do not change the plan.

## Import / Export / Cloud

Assist Actions:

- Export your settings
- Import a friend’s JSON
- Open [Cloud Configs](/features/cloud-configs)

Keybinds + Dev settings are preserved across cloud installs.
