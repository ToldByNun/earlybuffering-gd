# Common problems

Start here. Pick the closest match.

| Symptom | Go to |
|---|---|
| Assist too strong / floaty / never helps | [Feels wrong](/troubleshoot/feels-wrong) |
| Android / iOS missing binary | [Mobile](/troubleshoot/mobile) |
| Stutters, hitches, crashes | [Lag & crashes](/troubleshoot/lag) |
| Progress / leaderboard worries | [Safe Mode](/features/safe-mode) |
| Cannot find mod on Geode Index | Expected — [banned](/install/geode-index). Use [GitHub Releases](/install/github-releases) |
| Mod does not load | Wrong GD version? Need 2.2081. Reinstall Geode + `.geode` from Releases |
| Settings vanished after Cloud pack | Pack overwrote assist settings — re-import your export or reset |

## Fast reset profile

1. Assist Mode = Live  
2. Safe Mode = On  
3. Window = 4 ticks (unit = Ticks)  
4. Adaptive = Off  
5. Orbs = Off temporarily  
6. Learning / Self-Bake = Off  

Play. If still broken, it is probably install / scope / package — not “need more window”.
